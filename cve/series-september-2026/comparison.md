# Два зеро-дня одного Patch Tuesday рядом

Финальный файл серии [September 2026 Zero-Days](./README.md). Оба бага были
в диком обороте до патча, оба дают SYSTEM, оба пропатчены 8 сентября 2026.
И всё — дальше сравнение показывает, что «одинаковые зеро-дни» не бывают.

## Таблица

| | CVE-2026-85880 | CVE-2026-81963 |
|---|---|---|
| Компонент | Windows ALPC | Windows Update Stack |
| Класс | heap-based buffer overflow | link following (CWE-59) |
| Тип ошибки | memory corruption | логическая (пути/ссылки) |
| Эффект | LPE до SYSTEM | LPE до SYSTEM |
| CVSS | 7.8 | Important |
| Условия | локальный доступ | локальная аутентификация |
| Кто пишет | ALPC-сервер, принимающий сообщения | сервис, идущий по путям |
| Место фиксa | проверки границ в обработчике | разрешение ссылок до доступа |
| Технический writeup | на момент серии нет | частично (vendорские) |

## Что из этого следует

**1. Патчить надо оба класса — разными способами.** Memory corruption ловится
компилятором (ASan в тестах, /GS), link following — только дисциплиной
работы с путями (`FILE_FLAG_OPEN_REPARSE_POINT`, контроль владельца папок).
Один SAST-инструмент оба класса не поймает.

**2. CVSS 7.8 ≠ «не срочно».** 85880 с его «Important» был в диком обороте.
Реальная срочность = CVSS × эксплуатируемость × доступность цели, и второй
множитель решает.

**3. Класс определяет охоту.** ALPC-баги ищутся фаззингом/реверсом IPC-серверов
(см. [ALPC-праймер](./alpc-primer.md)), link following — ревью путей у
SYSTEM-сервисов (см. [чеклист](./link-following-hunting-checklist.md)).
Одна методология на оба класса не работает.

**4. Патч-диф остаётся главным источником.** Оба разбора — «что известно по
адвизори + план диффа». Когда появятся полные writeup'ы, они обновляются
обратно — честная эволюция документа вместо претендования на полноту.

## Что бы я сделал дальше, будь это пентест

- Развернуть лабу с уязвимой версией (до-патчные билды через Winbindex)
- Прогнать ALPC-сервер фаззером структур сообщений (для 85880)
- Прогнать Sysmon + junction-игры вокруг Update Stack (для 81963)
- Сверить наблюдения с патч-дифом — и это уже материал отдельного
  глубокого разбора, когда появятся чужие результаты для сверки
