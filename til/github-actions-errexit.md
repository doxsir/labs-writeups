# TIL: GitHub Actions выполняет run-блоки с bash -e

Дата: 2026-09-19

Написал в CI смок-тест вида:

```yaml
- name: smoke
  run: |
    out=$(./peep README.md)
    echo "$out" | grep -q "not an MZ"
```

И был удивлён, что шаг падает **до** grep. Оказалось GitHub Actions исполняет
`run:` через `bash -e {0}` — errexit. Команда, которая возвращает не-ноль,
валит шаг немедленно, даже если её результат ты хотел использовать дальше.

А `./peep README.md` возвращает exit 1 по дизайну: это негативный тест,
файл не PE — инструмент обязан вернуть ошибку.

Правильно так:

```yaml
run: |
  out=$(./peep README.md) || true
  echo "$out" | grep -q "not an MZ"
```

`|| true` глушит errexit для конкретной команды, а реальную проверку делает grep.
Занятно, что `; true` в конце строки не спасает — errexit срабатывает на строке
с ошибкой, а не в конце блока... хотя в моём случае была ещё и другая строка
после. Короче: любые команды с ожидаемым не-ноль exit code — только через `|| true`.

Проверено на собственном красном билде: doxsir/peep, первый CI-прогон.
