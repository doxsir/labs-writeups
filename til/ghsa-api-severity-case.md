# TIL: GitHub Advisory API капризничает на регистре severity

Дата: 2026-09-27 (заметил ещё при разработке cvedigest, оформляю только сейчас)

Гнал фильтр по severity через `/advisories?severity=HIGH` — получал 422.
`severity=high` — работает. При этом в **ответе** API то же самое поле
`severity` приходит в lowercase (`"severity": "high"`).

Итого неочевидное:

- в **query** параметре — только lowercase, иначе 422 с невнятным телом
- в **ответе** — тоже lowercase
- при фильтрации «не ниже» приходится строить таблицу рангов в lowercase и
  не забывать `.lower()` в каждом месте

Второй грабель: поле даты называется `published_at`, а не `published` —
как в REST-эндпоинтах большинства других API GitHub. Kotlin-нейминг
провалился сквозь землю непонятно куда.

Мораль: когда API возвращает «422 Unprocessable Entity» без подробностей —
проверь регистр значений enum-полей. Это самый дешёвый чек перед тем,
как перечитывать документацию.
